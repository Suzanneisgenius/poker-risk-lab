# Research overview

Open `index.html` directly, or run `npm start` and visit
<http://localhost:4174/dashboard/>. This is an offline presentation of saved
experiments, with filters and a simple EV illustration. It does not run server-side
calculation engines, accept personal session files or send data to a server.

Three views:

- **Research:** change saved simulation budgets and history lengths; compare
  continuous-monitoring uncertainty with a separately identified endpoint-only
  model stress test; inspect the 40 paired seeds behind the bridge correction.
- **Bankroll examples:** four existing validation scenarios and their saved risk
  curves. Posterior bounds, averages and plug-in results remain distinct.
- **Hand equity:** six postflop examples cross-checked against PokerKit; change
  pot/call amounts using their saved equity. No new range computation occurs.

`src/` contains the editable HTML, CSS and UI logic. `scripts/build_dashboard.js`
loads six saved JSON sources and embeds their hashes and selected results. Run
`npm run build` after edits. `npm test` checks data preservation, failed-source
handling, and the static artifact allowlist. No saved research outputs are
regenerated by the dashboard build.

Browser verification (Node 22):

```sh
npm --prefix checks/browser ci
npm --prefix checks/browser exec -- playwright install chromium
node checks/browser/dashboard.js
```

The check serves the Pages artifact under a repository subpath, blocks external
requests, exercises the filters, all examples, keyboard tabs, EV input errors,
JSON download and static links, and checks 1440/375 CSS-pixel layouts. It also
opens the standalone file directly. Outputs and environment details go to
`outputs/dashboard-check/`; it is not a real-device or screen-reader audit.

Chart.js 4.5.1 is vendored and embedded for offline use, under the accompanying
MIT license. Its copyright and license are included in the built page. The
server-side calculation code is neither imported nor embedded.

See [GitHub Pages instructions](../GITHUB_PAGES.md) for the explicit six-file
publication artifact. The source repository is public. A built artifact is not
proof of a live deployment.
